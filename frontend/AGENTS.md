# Руководство по фронтенду

## Структура

Фронтенд — приложение Next.js 16 на TypeScript с App Router и Tailwind CSS. Код приложения находится в `src/app/`, глобальные стили — в `src/app/globals.css`. Файлы конфигурации находятся в `*.config.*` и `tsconfig.json`.

## Разработка и проверка

Запускайте команды из каталога `frontend/`:

```sh
npm install       # установить зависимости
npm run dev       # запустить Next.js на localhost:3000
npm run build     # создать сборку для продакшена
npm run start     # запустить сборку для продакшена
npm run lint      # запустить ESLint
```

Перед отправкой изменений фронтенда выполните `npm run lint` и `npm run build`.

## Стиль и тесты

Используйте отступ в два пробела для JSON и файлов конфигурации; в TypeScript следуйте существующему стилю. Называйте компоненты React в PascalCase, хуки — с префиксом `use`, функции и переменные — в camelCase. Исправляйте замечания ESLint и TypeScript, вместо того чтобы подавлять их.

При добавлении тестов следуйте соглашениям выбранного для задачи фреймворка и используйте понятные имена, например `page.test.tsx`. Размещайте тесты рядом с проверяемым кодом или в каталоге с понятным названием для тестов.
