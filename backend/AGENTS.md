# Руководство по бэкенду

## Структура

Бэкенд — небольшой HTTP-сервер на Go. Точка входа находится в `cmd/server/main.go`, данные модуля — в `go.mod`. По мере развития приложения сохраняйте чёткую ответственность пакетов.

## Разработка и проверка

Запускайте команды из каталога `backend/`:

```sh
go run ./cmd/server  # запустить сервер на localhost:8080
go build ./...       # скомпилировать все пакеты Go
go test ./...        # запустить тесты Go
```

Перед отправкой изменений бэкенда выполните `gofmt` для изменённых файлов Go и `go build ./...`; после добавления тестов запускайте также `go test ./...`.

## Стиль и тесты

Используйте `gofmt` и принятые в Go соглашения об именах: экспортируемые идентификаторы — в PascalCase, локальные имена — в camelCase. Для тестов используйте стандартный пакет `testing`, называйте файлы `*_test.go` и размещайте их рядом с проверяемым кодом.
