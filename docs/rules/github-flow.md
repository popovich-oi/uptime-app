## GitHub Flow

- Перед началом каждой задачи создайте отдельную ветку из текущей ветки по умолчанию; не работайте непосредственно в `master` или другой общей ветке.
- Назовите ветви задач, используя тип и краткую транслитерированную функцию или исправьте имя: `feat/<transliterated-name>` для новой функциональности и `fix/<transliterated-name>` для исправлений ошибок.
- Используйте строчные латинские символы, разделяйте слова с дефисами и избегайте пробелов, препинания и кириллицы в названиях ветвей.
